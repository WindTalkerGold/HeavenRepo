# 一键成曲 · Piano Rhythm

单轨、单键钢琴节奏游戏。电脑按 **空格**，鼠标或手机/平板点按 **节拍键**：
音符到达金色判定线时按下，每个音符只按一次，长音不需要长按。
音乐会持续播放，错拍不会中断旋律。

## 曲目与声音

- 小星星：法国传统旋律 / 莫扎特变奏曲主题，入门。
- 欢乐颂：贝多芬第九交响曲主题，基础。
- 致爱丽丝：贝多芬 WoO 59 开头节选，进阶。
- G 大调小步舞曲：Christian Petzold，BWV Anh. 114 主题节选，进阶。

底层旋律属于公版。这些是为单键游戏新编的**简化钢琴节选**，不是完整原版乐谱，
也不是对现代录音的转录。伴奏为简易新编；和弦只产生一个击打目标，伴奏不增加目标。
琴声通过 Web Audio 谐波合成和衰减包络实时生成，无采样、无外部音频、字体或 CDN。

## 玩法

- 四拍预备；预备期可试按（第一音允许提前 125 ms 命中）。
- **Perfect：±55 ms**，基础 100 分；**Good：±125 ms**，基础 70 分。
- 每次命中额外奖励 `2 × min(当前连击, 50)` 分。
- **Miss（漏拍）**：断连，不扣分；**Off Beat（空按/错拍）**：断连、扣 30 分，最低 0 分。
- 准确率 = `(Perfect + 0.7 × Good) / (已判定音符 + 空按次数)`；最终评级 S ≥ 98%、A ≥ 90%、B ≥ 75%、C ≥ 60%，否则 D。
- 正确：绿色 / 金色闪光、扩散粒子、连击与时间偏差；错误：红色闪光、文字原因及轻微震动动画/低音提示。
- 0.75× / 1× / 1.25× 速度，可开启节拍器。
- 延迟微调范围 ±250 ms，**正值表示延后判定**；不是麦克风自动校准。推荐外放/有线耳机。
- `P` / `Esc` 或按钮暂停。页面隐藏、失焦、音频中断时自动暂停；继续后从原处恢复。
- 后台或严重卡顿造成的节奏中断无法完全消除，可选择重新开始本轮。
- 无账号、无排行榜、无 localStorage/IndexedDB、无文件访问，不保存任何历史或设置。

## 前端架构

无需 React/Vue 或打包器：原生 **ES Modules + Web Audio + Canvas 2D**，DOM 负责控制与可访问性。

```text
index.html           页面骨架、触屏大按键、语义控件、结果 dialog
style.css            响应式布局；手机演奏模式；减少动画偏好
js/songs.mjs         公版旋律新编谱面 + 节拍时间轴编译
js/engine.mjs        纯判定/计分模型，与浏览器和帧率无关
js/audio.mjs         Web Audio 时钟、提前调度、暂停、合成琴声
js/view.mjs          DPR 自适应 Canvas 轨道、判定线与粒子
js/app.mjs           状态机、界面绑定、统一输入、暂停/结算协调
```

- **谱面**：`音名:拍数`，例如 `C4:1 D4:0.5 -:0.5 E4+G4:2`。
  `-` 是休止，`+` 是和弦；支持升降音，时值单位为四分音符拍。
- **时钟**：以 AudioContext 时间为唯一传输时钟，支持时利用 `getOutputTimestamp()`
  对齐声音输出。25 ms 定时器仅向音频线程提前调度 180 ms，并不决定判定时间。
  Canvas 使用 requestAnimationFrame 查询同一时间轴，不累加帧间隔计分。
- **输入**：`keydown` 与 `pointerdown` 调用同一个判定入口。忽略键盘自动重复、
  非主触点和点击后的重复事件，按下立即判定，不等待 click / 抬手。
  大按钮禁用触摸滚动和长按菜单；其余页面正常滚动。
- **暂停**：挂起音频上下文和调度器，保留已调度的音符与当前进度；切换页面/曲目时清理声音。
- **触屏**：窄屏演奏时隐藏曲库，采用动态视口高度和安全区；支持减少动画偏好。
  仍保留下落音符等必要节奏信息，关闭装饰粒子/抖动动画。
- `../staticwebapp.config.json` 声明 `.mjs` MIME 类型，确保 Azure 可加载 ES Modules。

## 运行与测试

需要通过 HTTP(S) 加载 ES Modules，不能直接双击 HTML 用 `file://` 启动。
在仓库根目录：

```bash
python -m http.server --bind 127.0.0.1 -d site 8000
# http://localhost:8000/piano-rhythm/

npm ci
npm run test:unit     # 谱面、判定边界、重击/漏击、整曲计分
npm run test:rhythm   # 实际 Chromium 音频时钟 + 桌面/模拟触屏回归
npm test             # 包含原打字游戏的全部回归
```

浏览器测试使用已安装的 Edge/Chrome，找不到时设置 `BROWSER_PATH`。
可选 `SCREENSHOT_DIR` 保存桌面、手机和结果截图，不保存到静态站点目录。
触屏已通过 Chromium 移动设备模拟测试；真实 iOS/Android 的扬声器、蓝牙延迟和系统中断
仍建议实机体验，根据需要微调延迟。无 Web Audio 时会显示提示，不会假装已开始演奏。
