# 键盘小能手

纯 HTML / CSS / JavaScript 打字游戏，无后端、无构建步骤、无外部字体或音频依赖。
本次同步自 `D:\Coding\typing` 的工作目录（含尚未提交的音效和五线谱功能），
不包含其 Git 历史、开发环境、调试脚本或个人成绩。

## 功能

1. 字母 / 数字：不区分大小写，每个键对应固定音符。
2. 单字母 / 符号：区分大小写。
3. 英文单词：带中文释义。
4. 英文句子：包括空格与标点。
5. 中文单字：支持输入法合成。
6. 中文句子：支持输入法合成。

错误输入每次罚时 0.5 秒，仅在本轮结束时显示平均用时、最快用时和题数，不保留历史记录。
A–Z、0–9 共 36 个按键由 Web Audio 实时合成固定音符，配合 SVG 五线谱；
音符对照表可点击、键盘试听或依次播放。声音开关会保存在当前浏览器。

## 文件布局

```text
index.html      页面与脚本加载顺序
style.css       布局和动画
app.js          训练、计时、本轮结果
sound.js        按键音符映射与 Web Audio 合成
staff.js        五线谱 SVG 渲染
data/*.js       字母、单词、英文句子、中文题库
```

## 本地预览

从仓库根目录运行：

```bash
python -m http.server --bind 127.0.0.1 -d site 8000
```

打开 <http://localhost:8000/typing/>，也可以直接打开 `index.html`。
桌面浏览器配合实体键盘体验最佳；播放音效需要先点击页面或按键。
浏览器回归测试见仓库根目录 README 的 `npm test` 说明。
测试覆盖键盘输入、中文合成事件、不保存历史、旧记录清理和切题取消等逻辑；
真实中文输入法的候选词交互仍建议手动验证。

## 成绩与隐私

- 不保存历史成绩，没有排行榜、文件连接或成绩导出功能。
- 本轮结果只在页面内存中显示，刷新后消失，不上传服务器。
- 打开新版时会清除当前站点旧版的 `typing_scores` 本地存储和 IndexedDB 数据库。
  若仍有旧版标签页打开，请关闭旧标签页后刷新，以释放旧数据库连接。
- 以前手动导出的 JSON 文件不再读取或写入；磁盘上的旧文件不会自动删除。
- 仅声音开关偏好仍保存在浏览器，不包含任何训练历史。
